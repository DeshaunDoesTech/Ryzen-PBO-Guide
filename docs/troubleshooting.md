# Troubleshooting

## PC will not boot

Use the motherboard's documented BIOS recovery or Clear CMOS procedure, restore known-good settings, and reapply changes one category at a time.

## Random reboot, BSOD, or WHEA errors

Return the most recent tuning change toward stock. If Curve Optimizer is negative, reduce its magnitude and retest.

## Stress tests pass but games/idle crash

Curve Optimizer can fail in lightly threaded or low-load conditions. Add single-core, light-load, idle, sleep/wake, and real-application testing.

## Higher clocks but lower score

Check effective clocks, temperature, power/current limits, background applications, benchmark variance, and possible instability/clock stretching.

## Start over

Load BIOS defaults, restore only required non-CPU settings, benchmark stock, re-enable PBO, and reintroduce one tuning category at a time.
